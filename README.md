# mwri-news-collector
مجمّع أخبار «مرصد الري الذكي» — يستهدف جولة كل ١٥ دقيقة طوال اليوم ويكتب اللقطة المركزية فى قاعدة المرصد. قد تتأخر البداية إذا تأخر عامل GitHub أو طال الجمع.
مستودع عام عمداً: دقائق Actions للمستودعات العامة بلا حدّ. لا يحوى كود التطبيق ولا أى سرّ.
الزوايا تُقرأ من `sources-config.js` المنشور فى مستودع التطبيق (مصدر الحقيقة الواحد).

الجولات العادية تبحث فى آخر يوم؛ مرة كل ساعة تُوسَّع النافذة إلى سبعة أيام فى نفس الجولة، مع الاحتفاظ بالنتائج السابقة وإزالة التكرار. التوسيع لا يضاعف عدد طلبات الجولة. هذا بحث فى الخلاصات العامة وفهارس الأخبار، وليس وصولاً شاملاً إلى فيسبوك أو بحث ChatGPT مجدولاً.

الحارس يفحص الاستحقاق كل ٢٠ ثانية. تُحسب الـ١٥ دقيقة من بداية المحاولة، بما فيها المحاولة الفاشلة، وتُحسب الساعة من بداية آخر محاولة موسعة؛ الطلب اليدوى يبقى متاحاً. القيم lastAttemptAt وlastSweepAt فى عقدة المهمة بالثوانى؛ nextCollectionAt وحقول الوقت فى health بالمللى ثانية. موعد الجولة التالية تقدير للاستحقاق لا ضمان لوقت اكتمال الجمع.

للتحقق: `python3 -m unittest -v test_schedule.py`. يعرض سجل الجولة عدد المصادر الناجحة والنافذة المستخدمة وأخطاء المصادر. فتح التطبيق يستقبل اللقطة الجديدة عبر قناة المزامنة القائمة.
